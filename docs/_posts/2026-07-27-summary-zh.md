欧盟委员会提出一项新提案，允许用户通过浏览器一次性设置隐私偏好，从而替代网站上频繁出现的 Cookie 同意横幅，以此简化用户同意流程并加强隐私保护。 该提案若实施将显著改善网页浏览体验，解决 Cookie 横幅带来的“同意疲劳”问题，并推动基于浏览器的全球隐私控制（GPC）标准化，可能成为全球隐私法规的重要参考。 提案设想利用类似 Global Privacy Control（GPC）的技术，通过 HTTP 头部或浏览器 API 自动传递用户隐私偏好，但具体实现细节和网站端的强制力仍有待明确，社区期望能支持按站点自定义设置。

## [Apache Iceberg 提议增加 Variant 数据类型支持](https://github.com/apache/iceberg/issues/10392) ⭐️ 8.0/10

Apache Iceberg 社区提议为表格式增加 Variant 数据类型，该类型能以高效的二进制编码存储 JSON 等半结构化数据，从而提升查询引擎处理动态数据的灵活性和性能。 此提案将显著简化数据湖中对半结构化数据的处理，使 Iceberg 用户能够更高效地查询日志、埋点、物联网等动态数据，进一步巩固 Iceberg 作为湖仓一体核心格式的地位。 Variant 类型允许在列中直接以二进制格式存储与查询半结构化数据，避免了传统方案中需提前定义模式或解析 JSON 的开销。该提案仍处于评审阶段，未来将作为 Iceberg v3 规范的一部分引入。
