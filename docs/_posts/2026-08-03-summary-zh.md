## [Kakehashi：在 Linux ARM 上运行 macOS 二进制文件的实验性用户空间](https://github.com/wie-project/kakehashi) ⭐️ 7.0/10

这个名为 Kakehashi 的实验性项目可在 Linux ARM 设备上原生运行 macOS 命令行二进制文件，目前已有 7-Zip 和 curl 等工具的成功运行原型。 这填补了在非苹果 ARM 硬件上直接运行 macOS 软件的空白，为开发者提供了新的交叉平台兼容性可能性，可能推动类似 WINE/Proton 在 macOS 领域的生态发展。 目前 7-Zip 的运行速度比原生 Linux 版慢约 5.2 倍，但已有优化计划；curl 通过了超过 200 个命令和选项的自动化测试。项目处于早期阶段，仅支持命令行工具。

hackernews · vlad_kalinkin · Aug 2, 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49145937)

**背景**: 用户空间是指操作系统中供应用程序运行的内存区域，与内核空间分离以提供保护。二进制兼容性指一个系统能直接运行另一系统的可执行代码。类似项目 Darling 的目标也是在 Linux 上运行 macOS 软件，但主要针对 x86 架构，ARM64 支持仍在开发中。

RISC OS Open 庆祝其二十周年，Hacker News 上的相关帖子引发了早期开发者和用户的回忆与讨论，特别提到了该系统在 Raspberry Pi 上极快的启动速度。 这一里程碑凸显了 RISC OS 作为一个早期 ARM 操作系统所保持的持续社区支持，尽管其影响力有限，但对 ARM 计算历史仍有特殊意义，并展示了开源社区对复古技术的持久热情。 讨论中提及了全汇编编写的 !Director 桌面定制应用、RISC OS 上诞生的 Sibelius 乐谱软件，以及它在树莓派上比其它系统启动快得多的特点。

**背景**: 核心词汇列表基于语料库频率和教学需求筛选。1953 年的列表源于早期书面语料，侧重道德和集体美德；现代列表则从更大、更口语化的语料库提取，注重实用性和社会语境，体现文化变迁。
