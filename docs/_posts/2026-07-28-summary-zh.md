一位法官驳回了谷歌依据《数字千年版权法》（DMCA）提起的诉讼，该诉讼试图禁止第三方抓取其搜索引擎结果页面，法院认定抓取行为不构成版权侵权。 该裁决可能为网页数据抓取立下关键判例，影响搜索引擎结果的可访问性，并加剧数据控制与开放竞争之间的法律博弈，对依赖搜索数据的业务和研究人员影响深远。 案件涉及 SerpAPI 等抓取服务，谷歌曾停止提供官方搜索 API，迫使开发者依赖第三方抓取；法官可能认为搜索结果因缺乏独创性编排而不受美国版权法保护。

Misago 开源论坛项目从其代码库中移除了 React.js，转而采用 HTMX 实现 UI 交互，团队发现 HTMX 对于论坛软件更合适且更易维护。 此次迁移表明，对于以文本内容为主的 Web 应用，基于超媒体的轻量级方案可能比复杂的单页应用框架更高效，这一趋势可能影响其他传统 Web 项目的技术选型。 HTMX 通过自定义 HTML 属性直接支持 AJAX、CSS 过渡、WebSockets 和服务器推送事件，无需编写大量 JavaScript；但社区反馈在处理包含大量 DOM 更新的复杂交互时可能出现性能问题。

hackernews · Ralfp · Jul 27, 09:58 · [社区讨论](https://news.ycombinator.com/item?id=49067301)

**背景**: HTMX 是一个开源前端库，它扩展了 HTML，使得开发者可以直接在 HTML 中使用属性来实现现代用户界面交互，而无需 JavaScript。Misago 是一个使用 Python/Django 编写的开源论坛软件。React 是由 Facebook 开发的前端库，广泛用于构建单页应用，但对以内容展示为主的论坛来说，其复杂性和性能开销可能过大。
