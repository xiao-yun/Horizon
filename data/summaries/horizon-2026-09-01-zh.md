## [谷歌从 Chrome 应用商店移除 Manifest V2 扩展，包括 uBlock Origin](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) ⭐️ 8.0/10

谷歌已从 Chrome 应用商店移除 Manifest V2 扩展，其中包括广受欢迎的广告拦截器 uBlock Origin，用户被逐步推向 Manifest V3。 Chrome 占据全球浏览器市场主导地位，此举会削弱广告拦截能力并引发隐私担忧，可能促使更多用户转向 Firefox 等替代浏览器。 Manifest V3 对扩展拦截网络请求的方式施加了更严格的限制，导致 uBlock Origin 的完整功能无法在 Chrome 上继续使用；用户若想保留完整广告拦截能力，可考虑使用 Firefox 或仅安装功能受限的 uBlock Origin Lite。

hackernews · twapi · Aug 31, 21:10 · [社区讨论](https://news.ycombinator.com/item?id=49514878)

**背景**: Chrome 扩展基于 Manifest 文件运行，Manifest V2 是旧版规范，允许扩展通过更灵活的方式拦截和修改网络请求。Manifest V3 是谷歌推出的新版扩展平台，旨在提高安全性和性能，但限制了广告拦截器常用的 webRequest API，改用规则数量有限的 declarativeNetRequest。uBlock Origin 是 Raymond Hill 开发的开源内容过滤扩展，在 Firefox 和 Chromium 系浏览器中拥有大量用户。

rss · Simon Willison · Aug 30, 23:59

## [将安防摄像头改造成 BirdNET-Go 自动鸟类识别系统](https://jasontucker.blog/how-i-turned-my-security-cameras-into-an-automatic-bird-identification-system-with-birdnet-go/) ⭐️ 7.0/10

一位博主发布博文，分享如何将现有安防摄像头通过 RTSP 流接入 BirdNET-Go，实现全天候自动鸟类声音识别，无需额外专用麦克风。 这一做法展示了开源 AI 声学识别工具与常见安防硬件的低成本集成路线，让普通用户和自然爱好者也能利用手头设备参与鸟类监测与公民科学项目，降低了生物声学研究的进入门槛。 社区反馈指出了实际部署中的关键限制：部分摄像头内置麦克风无防风罩、风噪严重，且 Aqara 等摄像头固件仅支持 16kHz 采样率，而 BirdNET 期望 48kHz 音频，导致识别效果下降。解决方案包括外接高质量麦克风或改用树莓派；BirdNET-Go 支持 Docker 部署，也可在 macOS 上运行。

## [Apache Iceberg 提议支持默认值表达式](https://github.com/apache/iceberg/issues/17616) ⭐️ 6.0/10

Apache Iceberg 的 issue #17616 提出，在表规范中将默认值支持从静态值扩展为值表达式，使列默认值可以基于表达式计算；该提案引用了此前关于扩展 Iceberg 表达式的讨论，并关联了 Spec PR #16777。 该改动若被采纳，将允许 Iceberg 表 schema 使用动态默认值（例如当前时间戳、UUID 或基于其他列的计算结果），减少写入端处理逻辑并提升跨引擎一致性，对使用 Spark、Trino、Flink 等引擎的 Iceberg 用户有实际影响。 该提案目前仅勾选 Table 规范，View、REST、Puffin、Encryption 等规范尚未涉及；具体设计见提案文档，并与 Spec PR #16777 关联。社区讨论中暂无公开评论，因此尚不清楚更广泛的接受度。

github · danielcweeks · Aug 15, 00:51

**背景**: Apache Iceberg 是一种高性能开源表格式，用于管理数据湖中的大规模分析表，支持 Spark、Trino、Flink、Presto 等引擎并发安全读写。表规范定义了 schema 及列的默认值行为。默认值表达式属于表规范中 schema 定义的一部分，它允许默认值不是固定常量，而是可计算的表达式，从而在插入缺失字段时动态生成值。
