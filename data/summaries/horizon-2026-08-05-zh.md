**背景**: Kafka Connect 分布式模式下，有 Coordinator 和多个 Worker 节点，协调器管理连接器配置和状态，通过控制主题存储元数据。Iceberg Kafka Connect 是连接器，将 Kafka 数据写入 Apache Iceberg 表。背压指下游系统处理能力不足时，上游需要限速以避免缓冲区溢出。当 Coordinator 过载时，控制主题消息堆积可能导致 Worker 重复请求，加剧问题。

## [Apache Iceberg 提议在 REST Catalog 的 LoadTableResponse 中添加标签元数据](https://github.com/apache/iceberg/issues/15521) ⭐️ 6.0/10

Apache Iceberg 的 GitHub 提案 #15521 计划为 REST Catalog 的 LoadTableResponse 增加一个可选的 labels 字段，使目录能以供应商中立的方式暴露表级上下文元数据，如所有权、分类、成本归属等。 该标准化字段有助于提高互操作性，允许开源引擎消费这些元数据，避免各目录采用专有扩展，同时为数据治理和成本归因等场景提供统一接口。 labels 字段为可选，具体格式尚未最终确定，可能会支持键值对或更复杂的结构，但提案强调其目的是保持通用性和简洁性。

github · laskoviymishka · May 12, 08:00

**背景**: Apache Iceberg 是一种开放表格式，其 REST Catalog 规范允许不同语言和引擎通过 REST API 与目录交互，而不依赖于特定语言的实现。LoadTableResponse 是加载表时返回的响应对象，目前包含 schema、快照等信息，但缺少传递目录维护的其他上下文（如标签）的标准方式。该提案填补了这一空白。
